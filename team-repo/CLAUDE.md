# Shop: team instructions

A small Python shop backend. Every teammate gets these instructions, because this file is in the repo.

- Run tests with `uv run pytest -q`. Run them before saying any change is done.
- Keep changes small and focused; don't reformat files you didn't change.
- Never commit secrets. Credentials come from environment variables.
